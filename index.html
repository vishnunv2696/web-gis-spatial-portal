GeoVista Portal Vector-Focused WebGIS

"Explore, analyze and share vector data in one place"

GeoVista Portal delivers modern geospatial visualization and client-side geoprocessing directly in your browser with zero backend dependencies and zero API keys.

Tech Stack

  • Mapping Engine: Leaflet 1.9.4
  • Geoprocessing: Built-in vector analysis engine (Search, Filter, Calculator & Statistics, Buffer, Nearby Proximity, Spatial Join, Buffer Impact, Measurement)
  • Marker Clustering: Leaflet.markercluster 1.5.3
  • Architecture: Vanilla ECMAScript Modules (ESM)
  • Coordinate System: EPSG:4326 (WGS 84)
